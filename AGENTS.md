# Project instructions

- Use Astro for pages and layouts, TypeScript for new application code, and native browser APIs for simple interactions.
- Keep individual stories in `src/stories/<slug>/`. Register their metadata in `src/data/case-studies.ts` and add a corresponding route under `src/pages/stories/`.
- `dist/` is generated. Do not edit it directly.
- Preserve keyboard support, reduced motion, and readable mobile layouts.
- Do not present fictional examples as production metrics or customer data.
- Do not add Co-authored-by trailers or other AI attribution to commits.
- Run `npm run check` and `npm run build` after changes.
